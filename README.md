## О моде

У каждого взрыва появляется настоящая ударная волна: она идёт от места взрыва, бьёт стёкла, распахивает и срывает двери, трескает кирпич, сбивает факелы и траву, поднимает пыль по земле, а тех, кого накрыло, контузит — звон в ушах, заложенные уши, двоение и красно-голубое расслоение картинки, покачивание камеры.

Мод работает с **любым** взрывом, который проходит через ванильный класс `Explosion`: динамит, криперы, кровати, кристаллы Края, иссушитель и снаряды **Create: Big Cannons** (их взрывы наследуют ванильный класс, мод ловит их через событие `ExplosionEvent.Detonate`, без жёсткой зависимости).

## Возможности

### Взрыв, звук и земля

- **Сам взрыв.** Короткая слепящая вспышка, огненный шар из нескольких клубов (раскалённый добела, остывает через оранжевый и красный в дым), искры-трассеры по дугам, комья грунта из воронки и столб копоти, который медленно сносит ветром. Всё масштабируется с мощностью. Серые ванильные клубы убираются — если волны у взрыва нет, они всё равно появятся.
- **Гром с задержкой.** Мгновенный ванильный звук взрыва заменяется громом, который приходит вместе с волной: вблизи хлёсткий удар с сабвуферным «бумом» и шорохом обломков, вдали — глухой раскатистый гул с эхом. Слышно до 60 блоков на единицу мощности (динамит — ~240 блоков, в ванилле — 64). У взрывов других модов свой звук, его мод не трогает.
  - Семь вариантов ближнего и семь дальнего грома: четыре сгенерированных (шумовые, с рваной атакой и эхом) и три записанных взрыва, приведённых к моно и к той же громкости; высота каждый раз немного другая.
  - В серии слышен каждый взрыв; идущие вплотную друг за другом чуть тише, одновременно звучат не больше пяти — цепочка динамита звучит как канонада, а не как барабаны.
- **Снаряд по дереву.** Когда снаряд Create: Big Cannons бьёт в доски или брёвна, вместо его звука щепок играет тяжёлый треск ломающегося дерева (настройка «Попадание снаряда в дерево»).
- **Толчок по земле.** Идёт в три раза быстрее воздушной волны и приходит первым: камера мелко дрожит, снизу поднимается гул; если над головой крыша или свод пещеры, с потолка сыплется пыль и крошка того самого блока.
- **Обвалы.** Толчок роняет сталактиты (остриё ранит, как у ванильного падающего сталактита), гравий и песок, нависающие над пустотой. Стены от этого не защищают — толчок идёт через породу.
- **Лампы.** Лампы и медные лампы вокруг игрока мигают с треском, когда до них доходит волна или толчок. Это только картинка у игрока: мир не меняется, лампа потом горит как прежде.
- **Огонь.** Свечи и торты со свечами задувает, костры гаснут, трава у самой воронки выгорает до земли.
- **Пушки Create: Big Cannons.** Выстрел бьёт по камере в момент, когда до игрока доходит звук (CBC сам задерживает звук по расстоянию), сила — по числу зарядов пороха. Рядом с большой пушкой расчёт получает кратковременный звон в ушах.

## Как устроена волна

- **Давление.** Избыточное давление на фронте считается по эмпирической формуле М. А. Садовского для воздушного взрыва:
  `ΔP = 0,84/Z + 2,7/Z² + 7/Z³` бар, где `Z = r / (мощность × chargeScale)`.
  Мощность — радиус взрыва в Minecraft (динамит 4, заряженный крипер 6, снаряд CBC — сколько выставлено в его конфиге). Чем сильнее взрыв, тем дальше всё достаёт.
- **Скорость.** Фронт вблизи сверхзвуковой (число Маха из соотношения Ренкина–Гюгонио) и замедляется до скорости звука. Скорость по умолчанию уменьшена в 10 раз, чтобы волну было видно.
- **Укрытие.** От точки взрыва до блока или существа проводится луч: сплошные блоки гасят волну (камень — до 30 % на блок), стёкла и двери — меньше. За толстой стеной стекло уцелеет, и контузии не будет.
- **Несколько взрывов разом** (цепочка динамита) в одном тике складываются в одну волну по энергии.

## Что происходит с блоками

Настройки по умолчанию, взрыв динамита:

| Порог, бар | Что | Примерно на скольких блоках от динамита |
|---|---|---|
| 0,05 | стекло, стеклянные панели, окна Create — вдребезги, осколки летят дальше | ~24 |
| 0,07 | деревянные и медные двери, люки, калитки распахиваются | ~18 |
| 0,12 | снег сдувает | ~12 |
| 0,18 | факелы, фонари, свечи, цветочные горшки сбивает | ~9 |
| 0,22 | трава, папоротники, цветы | ~8 |
| 0,3 | кирпич, каменный кирпич, адский кирпич → потрескавшийся | ~6,5 |
| 0,35 | двери срывает с петель | ~6 |
| 0,4 | листву обрывает | ~5,5 |
| 0,75 / 0,9 | потрескавшийся / целый кирпич выбивает из кладки, он летит дальше по ходу волны | ~3,5–4 |
| 0,06 | свечи задувает | ~20 |
| 0,12 | толчок роняет сталактиты, гравий и песок над пустотой | ~12 |
| 0,2 | костры гаснут | ~8 |
| 1,2 | трава, подзол, мицелий, тропинка выгорают до земли | ~3 |

У порога блок поддаётся примерно в трети случаев, при превышении в полтора раза — всегда, поэтому край зоны разрушений рваный, а не циркульный.

Для обычного красного кирпича, у которого нет ванильной потрескавшейся версии, мод добавляет блок **«Потрескавшиеся кирпичи»** (выпадает сам, делается переплавкой кирпичного блока).

### Датапак

Всё это данные, а не код: дата-мап `data/blastwave/data_maps/block/blast_response.json` и теги в `data/blastwave/tags/block/`. Датапаком можно добавить любые блоки из других модов:

```json
{
  "values": {
    "somemod:paper_wall": { "stages": [ { "pressure": 0.04, "action": "break" } ] }
  }
}
```

Действия:

- `shatter` — исчезает без дропа, осколки
- `break` — выпадает предметом
- `remove` — сдувает без дропа
- `open` — распахивает
- `replace` + `result` — превращает в другой блок
- `dislodge` — выбивает блок, он летит по ходу волны и падает обломком
- `shake` — падает, если под ним пусто; давление считается сквозь породу
- `extinguish` — гасит всё, у чего есть свойство `lit`

Какие лампы мигают, задаёт тег `blastwave:flickers` (блок должен иметь свойство `lit`).

## Контузия

Эффект **«Контузия»** (иконка — ухо со звоном) — от 2 до 15 секунд и уровни I–IV в зависимости от давления. Слегка замедляет. У игрока на клиенте:

- **звон в ушах** — тон ~4 кГц с биениями, громкость следует за силой контузии;
- **заложенные уши** — все звуки мира проходят через фильтр низких частот OpenAL;
- **экран** — двоение, красно-голубое расслоение (как анаглиф), размытие к центру, вуаль;
- **камера** — резкий толчок с наклоном головы от взрыва и затем покачивание.

Молоко снимает контузию, как и любой эффект. Боссы (иссушитель, дракон) не контузятся.

Даже без контузии игрок чувствует волну: глухой удар воздуха со стороны взрыва, толчок камеры и кольцо искажения, которое «обволакивает» и уходит дальше. Сам фронт виден издалека как дрожащий преломляющий пузырь.

## Совместимость

### Sable (необязательно)

Если установлен [Sable](https://modrinth.com/mod/sable) 2.0.5 или новее (физическая библиотека от команды Create Aeronautics), взрыв выбрасывает из воронки куски по 1–3 блока как настоящие твёрдые тела: они летят по дуге, кувыркаются, отскакивают, сталкиваются друг с другом и с постройками. Волна так же выбивает кирпичи из стен — они вылетают кувыркаясь, а не падают столбиком.

- Кусков за взрыв — до 12 (динамит бросает около 8), в измерении одновременно — до 48.
- Когда кусок улёгся (или пролетал 20 секунд), его блоки ложатся завалом там, где он остановился. Если там нет места — рассыпается пылью и выпадает предметом.
- Сундуки и другие блоки с содержимым, динамит и огонь не выбрасываются никогда.
- Трава, цветы, тростник, факелы и прочее без коллизии тоже не выбрасываются: для Sable они ничего не весят, а тело без массы роняет его физику, как только рядом вода. Такие блоки просто разносит взрывом, как обычно.
- Блоки кораблей и других объектов Sable, попавшие во взрыв, мод не трогает — их разрушает сам Sable.
- Если кусок в полёте задело вторым взрывом, на землю ложится только то, что от него осталось.
- Если игрок ушёл и кусок выгрузился вместе с чанком, он остаётся обычным объектом Sable.
- В начале каждого тика, до шага физики, мод убирает опустевшие и невесомые объекты Sable, которые Sable сам удалил бы только после этого шага. Поэтому такой объект уже не уронит физику у воды, даже если его собрал не Blast Wave.

Без Sable мод работает как прежде: выбитый волной кирпич падает обычным падающим блоком. Настройки — раздел «Разлёт обломков (Sable)»: `physicsDebris`, `debrisPerExplosion`, `debrisLifetime`, `debrisRubble`, `maxDebris`.

### Iris и Sodium

Проверено с Sodium 0.8.12 и Iris 1.8.14-beta.1 на NeoForge 21.1.250: без шейдерпака и с шейдерпаком Spooklementary 2.0.4 (семейство Complementary). Работает всё: огненный шар, дым, искры, пыль, мигание ламп, пыль с потолка, экран контузии, звуки. Преломляющий купол фронта при шейдерпаке тоже рисуется и правильно прячется за блоками: Iris пишет глубину сцены в общий буфер, которым пользуется мод. Если какой-то пак нарисует купол неправильно, его можно выключить только для шейдерпаков — настройка «Преломление с шейдерпаком» (`distortionWithShaders`).

Шейдерпак сам решает, как смешивать частицы, поэтому аддитивное свечение вспышки и искр под шейдерами выглядит слабее, чем без них.

Шейдерпаки, которым нужно больше 16 буферов (`colortex16`–`colortex31`), под Minecraft 1.21.1 не загружаются вообще: Iris 1.8 для этой версии поддерживает только 16. Iris пишет в чат «Render target with index … is not supported». Мод тут ни при чём — так, например, ведёт себя Derivative 25.1.0.

### Sound Physics Remastered

Если стоит Sound Physics Remastered, мод не трогает фильтры звука (они там заняты).

## Установка

1. Установите **NeoForge 21.1.x** для Minecraft **1.21.1**.
2. Положите `blastwave-2.1.4.jar` в папку `mods` **и на сервере, и у клиентов**.
3. Запустите игру.

Опционально: [Sable](https://modrinth.com/mod/sable) 2.0.5+ для физических обломков, Sodium/Iris для шейдеров.

## Настройки

Меню модов → Blast Wave, или файлы в папке сервера/мира:

- `serverconfig/blastwave-server.toml` — правила мира: дальность (`chargeScale`), скорость звука, затухание, разрушение блоков, `respectMobGriefing`, дроп, отбрасывание, порог контузии, лимиты производительности.
- `config/blastwave-client.toml` — у каждого игрока своё: преломление фронта, плотность пыли, сила экранного эффекта, тряска камеры, громкость звона, заложенные уши, эффекты взрыва, скрытие ванильных клубов, гром с задержкой, сила толчка по земле, мигание ламп, отдача пушек, преломление фронта при шейдерпаке.

## Команды

`/blastwave emit <x y z> <мощность> [ломать блоки]` — пустить волну без самого взрыва (нужен уровень OP 2). Удобно подбирать настройки:

```
/blastwave emit ~ ~ ~ 20 4
```

## API для других модов

Для модов, чьи взрывы не используют ванильный класс:

```java
dev.blastwave.wave.WaveManager.emit(ServerLevel level, Vec3 pos, float power, boolean damageBlocks);
```

## Сборка из исходников

Нужен JDK 21 (Gradle найдёт сам или скачает).

```bash
./gradlew build              # мод: build/libs/blastwave-2.1.4.jar
./gradlew runClient          # клиент с модом
./gradlew runGameTestServer  # автотесты волны на headless-сервере
```

### Автотесты

`src/gametest` строят арену и проверяют: стекло на 8 и 15 блоках разбито, стекло за двойной каменной стеной цело, дверь распахнута, кирпич и каменный кирпич потрескались, факел сбит, свинья контужена, настоящий взрыв динамита тоже запускает волну, сталактит падает от толчка, свечу задувает, костёр гаснет, а с установленным Sable — взрыв выбрасывает физические обломки, через отведённое время все они улеглись завалом, а взрыв на лугу у пруда не выбрасывает ни одного невесомого куска (трава, цветы, тростник). В jar мода тесты не попадают.
